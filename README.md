# Finanzas del Ser · Sitio web

Proyecto final de **Herramientas de Diseño Gráfico · Ingeniería de Software** (TdeA).
Sitio web responsivo de 4 páginas para Finanzas del Ser, hecho con HTML, CSS y JavaScript sin frameworks.

## Ver el sitio
Abre `index.html` en el navegador. No necesita instalación ni servidor.

## Estructura
- `index.html`, `servicios.html`, `quienes-somos.html`, `contacto.html`
- `css/styles.css`: todo el estilo. La paleta, las fuentes y los tamaños están en `:root` (variables).
- `js/main.js`: menú del celular y formulario visual.
- `assets/`: imágenes e íconos.
- `docs/DOCUMENTO_TECNICO.md`: guía de estudio para la sustentación.

## Estado
Logo e imagen del hero **provisionales**, a la espera de la identidad gráfica final (Illustrator y Photoshop).
Los detalles y pendientes están en `docs/DOCUMENTO_TECNICO.md`, sección 9.
